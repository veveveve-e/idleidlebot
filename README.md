# idleidle-bot
основная идея - инкрементальная игра (кликер) . в ней есть :

- некоторый юнит (не важно , что это , главное - его количество) ;
- скорость получения , измеряется в юнитах в секунду (изначально 0) ;
- некоторые постройки которые можно купить за юниты . они некоторым образом увеличивают скорость получения юнитов .
