# idleidle-bot

основная идея - инкрементальная игра (кликер) . в ней есть :

- некоторый юнит (не важно , что это , главное - его количество) ;
- скорость получения , измеряется в юнитах в секунду (изначально 0) ;
- некоторые постройки которые можно купить за юниты . они некоторым образом увеличивают скорость получения юнитов .

## задача 1

реализовать базовый функционал

### пример пользования

базовые возможные команды :

- /start - начало игры ;
- /help - выводит список возможных команд на данный момент игры (выводить при неизвестной команде ?);  
- /claim - собирает доступные юниты с построек ;  
- /build - управление постройками :  
    * /build - для просмотра доступных построек и их стоимости ,  
    * /build [number] - для покупки постройки (покупается всегда максимально возможное число постройки) ,  
    * /build max - для покупки всех возможных построек (не обязательно для реализации , чисто для удобства пользователя).  
- /stats - выводит статистику по пользователю (добавить в задаче 2 ?):  
    * /stats - базовая статистика (юниты + юниты/сек + время клэйма (? по мере добавления)) + варианты углубленного просмотра ,
    * /stats buildings - статистика по постройкам (количество + юниты/сек по постройкам) ,
    * ... другие статистики по мере развития игры ...

пользователь отправляет /start для начала игры . ответ :  
"игра началась .  
пропишите /claim для сбора ваших первых юнитов .  
пропишите /help для ознакомления ."  

пользователь отправляет /help . ответ :  
"/claim - для сбора юнитов ,  
/build - для просмотра построек ,  
/build [number] [amount] - для покупки построек ,  
/build [number] max - для покупки максимального количества постройки ,  
/build max - для покупки всех возможных построек .  
[дополняется по мере добавления функционала/достижения пользователем майлстоунов]"  

пользователь отправляет /claim . ответы :  

- стандартный ответ :  
    "получено [amount] юнитов за [amount] минут .  
    текущий баланс : [amount] юнитов ."
- недостаточно времени между клэймами :  
    "собирать нечего ! подождите ." (выводить время до следующего клэйма ??)
    
пользователь отправляет /build . ответ :  
"1 . [name] (приносит [amount] юнитов/сек) - [amount] юнитов/шт (построится [amount] штук)  
2 . [name] (приносит [amount] юнитов/сек) - [amount] юнитов/шт (построится [amount] штук)  
..."

пользователь отправляет /build [number] . ответы :

- стандартный ответ (юнита достаточно для постройки) :  
    "построено [amount] постройки [number] .  
    новая скорость : [amount] юнитов/сек .
    баланс : [amount] юнитов ."
- недостаточно юнитов :  
    "недостаточно юнита ! вы не можете это построить ."
    
пользователь отправляет /build max . ответы :

- стандартный ответ (юнита достаточно для постройки) :  
    "построены  все постройки , что можно построить .  
    новая скорость : [amount] юнитов/сек .
    баланс : [amount] юнитов ."
- недостаточно юнитов :  
    "недостаточно юнита ! вы не можете это построить ."

пользователь отправляет /stats . ответ :
"имя пользователя : [name]
количество юнитов : [amount] юнитов
юнитов собрано за все время : [amount] юнитов
скорость : [amount] юнитов/сек."
